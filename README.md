## 提交规范

一次实验 = 一个分支（`lab1`、`lab2`…），分支下固定两个文件夹：

- `code/` — 该实验实现后的完整代码
- `report/` — `report.md`（实验报告）、`prompt.md`（提示词汇总）、`images/`（测试截图）
