| 步骤 | 命令（节选） | 作用 |
|------|-------------|------|
| 1 | `$(CC) ... -c $< -o $@` | 把 `libs/`、`kern/` 下的 `.c` / `.S` 逐个交叉编译成 `.o`（放入 `obj/`） |

| 3 | `$(OBJDUMP) -S bin/kernel > obj/kernel.asm` | 生成带源码的反汇编，供调试 |

### GDB 调试体验

**负责人：** 【学号2-姓名2】

**涉及的关键地址：**

```
0x00001000    RISC-V 复位向量 —— QEMU 上电后执行的第一条指令
0x80000000    OpenSBI 固件基址 —— 完成最基本的硬件初始化
0x80200000    内核链接基址（BASE_ADDRESS）—— 我们自己的代码从这里开始
```

**调试流程：**

```bash
# 终端 1：以调试模式启动 QEMU（-s -S 挂起并监听 :1234）
make debug

# 终端 2：连接调试桩
make gdb
# 等价于：
# riscv64-unknown-elf-gdb \
#   -ex 'file bin/kernel' \
#   -ex 'set arch riscv:rv64' \
#   -ex 'target remote localhost:1234'
```

**要观察的现象（截图存 `images/`）：**

| # | 操作 | 预期 |
|---|------|------|
| 1 | `b *0x1000` → `c` | PC 停在 0x1000（复位向量） |
| 2 | `si` 若干次 → `x/10i $pc` | 指令流把 PC 带向 0x80000000 |
| 3 | `b *0x80000000` → `c` | 进入 OpenSBI |
| 4 | `b *0x80200000` → `c` | PC 落在内核入口 `kern_entry` |
| 5 | `info registers` | `sp` 指向 `bootstacktop` |
| 6 | `c` | 终端打印 `(THU.CST) os is loading ...` |
