### 功能模块：源码与调用链原理分析

**负责人：** 【学号3-姓名3】

#### 模块功能描述

**调用链：**

```
上电 → 0x1000（复位向量）→ 0x80000000（OpenSBI）→ 0x80200000
     → kern_entry                 (kern/init/entry.S)
         la sp, bootstacktop          设置内核栈
         tail kern_init               尾调用，跳转到 C 代码
     → kern_init                  (kern/init/init.c)
         memset(edata, 0, end - edata)    清空 BSS 段
         cprintf("(THU.CST) os is loading ...\n\n")
     → cprintf → vcprintf → vprintfmt → cputch → cons_putc
     → cons_putc → sbi_console_putchar        (kern/driver/console.c)
     → sbi_call(SBI_CONSOLE_PUTCHAR, ...) → ecall   (libs/sbi.c)
     → OpenSBI 处理 ecall，把字符写到串口 → 终端显示
```

**关键文件与作用：**

| 文件 | 作用 |
|------|------|
| `tools/kernel.ld` | 链接脚本：`ENTRY(kern_entry)`，`BASE_ADDRESS = 0x80200000`，定义 `etext` / `edata` / `end` |
| `kern/init/entry.S` | 入口汇编：把栈顶设为 `bootstacktop`，`tail kern_init` |
| `kern/init/init.c` | `kern_init`：清 BSS，打印 `(THU.CST) os is loading ...`，随后进入死循环 |
| `kern/driver/console.c` | `cons_putc` / `cons_getc`：控制台字符收发，转发给 SBI |
| `libs/sbi.c` | `sbi_call`：通过 `ecall` 陷入 OpenSBI，封装 `sbi_console_putchar`、`sbi_set_timer` |
| `kern/libs/stdio.c` | `cprintf` / `vcprintf`：格式化输出，最终逐字符调用 `cons_putc` |
