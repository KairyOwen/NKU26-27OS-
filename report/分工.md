## 一、实验范围与整体主线

本实验必须先补回 Lab2 的物理内存初始化和 Best-Fit 实现，再完成 Lab3 两个功能模块：

1. Trap 上下文恢复与入口：实现 `kern/trap/trapentry.S` 中的 `RESTORE_ALL` 和 `__alltraps` 调用逻辑。
2. 中断与异常处理：实现 `kern/trap/trap.c` 中的 `interrupt_handler()` 与 `exception_handler()`，处理时钟中断、非法指令与断点异常，并完成其他类型的提示与兜底输出。

整体执行链：

```text
启动并初始化物理内存
    -> idt_init 设置 sscratch、stvec
    -> clock_init 设置首个时钟事件并使能 sie.STIE
    -> intr_enable 设置 sstatus.SIE
    -> Trap 发生，硬件更新相关 CSR
    -> __alltraps / SAVE_ALL 构造 trapframe
    -> trap(tf) / trap_dispatch 分发
    -> interrupt_handler 或 exception_handler
    -> __trapret / RESTORE_ALL / sret
    -> 返回原执行流
```

上图描述功能关系；源代码中已有的初始化顺序和两次 `idt_init()` 暂时保留，不为整理流程随意改动，评分注入脚本会定位这些调用。

## 九、共同答辩重点

8. 10 MHz、100000、10 ms、100 ticks 之间的关系。
9. 定时器一次性事件重设、统计次数与关机条件。
10. 关中断、恢复旧中断状态、volatile、AMO 和多核锁之间的区别。
